# Outlook AI Assistant

Automatically reads the latest Outlook emails  
and sends them to an AI assistant for summarization.

## Features

- Automatically opens Outlook
- Reads the latest emails
- Filters pinned emails
- Generates AI prompts automatically
- Opens Doubao automatically
- Sends email summaries automatically
- Supports startup auto-run

## Tech Stack

- Python
- Selenium
- PyAutoGUI
- Pyperclip

## Workflow

1. Open Outlook
2. Read the latest emails
3. Extract sender and title
4. Generate summary prompt
5. Open Doubao
6. Send prompt automatically
7. Receive AI-generated summary

## Project Status

Personal automation project for improving daily email management and productivity.
